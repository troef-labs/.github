# Troef

An open-source loyalty card wallet that never tracks you.

- Store, show and organise your loyalty cards fully offline, no account needed
- Optional end-to-end encrypted sync across devices, shared with up to 6 family members
- Self-host the sync server for free from one Docker image, or use Troef Cloud
- English and Dutch at launch

Troef is in development. The source opens with version 1, first on Android and iOS.
